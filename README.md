# Rock-paper-scissor-game
A simple and interactive Rock Paper Scissors Game built using Python. This project allows users to play the classic Rock, Paper, Scissors game against the computer.  The computer randomly selects Rock, Paper, or Scissors, and the winner is decided based on the traditional game rules.

🎮 Features
Play against the computer.
Random computer choices using Python's random module.
Automatic winner detection.
User-friendly and simple interface.
Option to play multiple rounds.
🛠️ Technologies Used
Python
Random Module
Conditional Statements
Loops
🚀 How to Run
Clone this repository:

bash
git clone YOUR_REPOSITORY_URL
Open the project folder.
Run the Python file:

bash
python main.py
📌 Game Rules
Rock beats Scissors.
Scissors beats Paper.
Paper beats Rock.
If both players choose the same option, it's a Draw!
👨‍💻 About
This project was created to practice Python programming concepts such as conditional statements, loops, user input, and random number generation.
